# Changelog

Lanzamientos principales de la especificación BSP. Para cambios a nivel de código, ver los [releases en GitHub](https://github.com/Biological-Sovereignty-Protocol/bsp-spec/releases).

## v1.0.0 — Actual

**Migración Aptos + Arweave · Licencia MIT · Lanzamiento público**

- Capa de ejecución migrada a Aptos (contratos Move) con finalidad sub-segundo.
- Capa de almacenamiento permanente en Arweave.
- Release open source completo bajo licencia MIT.
- Taxonomía de biomarcadores v1 — 210+ biomarcadores en 4 niveles (Core, Standard, Extended, Device).
- Carta de gobernanza — multisig 2-de-3 para upgrades de protocolo (ver BIP-0001).
- SDKs: TypeScript, Python. CLI y servidor MCP publicados.

## v0.9.0

**Reescritura en Move**

- Contratos inteligentes reescritos en Move.
- Módulos BEO, IEO y ConsentToken separados en paquetes Move independientes.
- Control de acceso reforzado con resource accounts.
- Exchange protocol v2 — streaming bidireccional para datos de wearable.

## v0.8.0

**Primer borrador de especificación**

- Primer borrador público de la especificación BSP.
- Definición de los esquemas BEO, IEO y BioRecord.
- Introducción del modelo ConsentToken.
- Taxonomía inicial cubriendo ~120 biomarcadores centrales.
- Proceso de gobernanza (BIPs) formalizado.
