# Changelog

Lançamentos principais da especificação BSP. Para mudanças em nível de código, ver os [releases no GitHub](https://github.com/Biological-Sovereignty-Protocol/bsp-spec/releases).

## v1.0.0 — Atual

**Migração Aptos + Arweave · Licença MIT · Lançamento público**

- Camada de execução migrada para Aptos (contratos Move) com finalidade sub-segundo.
- Camada de armazenamento permanente em Arweave.
- Release open source completo sob licença MIT.
- Taxonomia de biomarcadores v1 — 210+ biomarcadores em 4 níveis (Core, Standard, Extended, Device).
- Carta de governança — multisig 2-de-3 para upgrades de protocolo (ver BIP-0001).
- SDKs: TypeScript, Python. CLI e servidor MCP publicados.

## v0.9.0

**Reescrita em Move**

- Contratos inteligentes reescritos em Move.
- Módulos BEO, IEO e ConsentToken separados em pacotes Move independentes.
- Controle de acesso fortalecido com resource accounts.
- Exchange protocol v2 — streaming bidirecional para dados de wearable.

## v0.8.0

**Primeiro draft da especificação**

- Primeiro draft público da especificação BSP.
- Definição dos schemas BEO, IEO e BioRecord.
- Introdução do modelo ConsentToken.
- Taxonomia inicial cobrindo ~120 biomarcadores centrais.
- Processo de governança (BIPs) formalizado.
