# Team

BSP is stewarded by the [Ambrósio Institute](https://ambrosioinstitute.org) and a distributed group of open source contributors working on protocol design, cryptography, SDKs, and documentation.

## Core contributors

The protocol is maintained by contributors across biology, cryptography, distributed systems, and health informatics. Individual attribution is handled at the repository level — see commit history and `CONTRIBUTORS.md` in each repo.

Public roles:

- **Specification stewardship** — Ambrósio Institute
- **SDKs (TypeScript, Python)** — open source maintainers
- **Smart contracts (Move)** — open source maintainers
- **Governance multisig** — 2-of-3 held by Ambrósio Institute + protocol owner

## Working groups

- **Taxonomy WG** — biomarker coverage, reference ranges, evidence grading
- **Schema WG** — BEO, IEO, BioRecord evolution
- **Security WG** — cryptography, key management, audit coordination
- **Ecosystem WG** — SDKs, integrations, certification
